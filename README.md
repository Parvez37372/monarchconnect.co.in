# 🏗️ Monarch Connect

### Build Better. Build With Trust.

**Monarch Connect** is a digital platform designed to connect homeowners, consumers, builders, contractors and construction professionals.

The platform helps people discover trusted construction professionals and enables builders and companies to showcase their expertise, projects and services.

🌐 **Live Website:** https://monarchconnect.co.in/

---

## 🚀 About the Project

Monarch Connect aims to make finding reliable construction professionals easier.

Whether someone is planning their dream home, starting a commercial construction project or growing a construction business, Monarch Connect helps bring the right people together.

Our goal is to create a trusted construction ecosystem where credibility matters and quality work gets recognised.

## ✨ Key Features

- **Professional Connections:** Connect homeowners with builders and construction professionals.
- **Business Login:** Dedicated access for businesses.
- **Consumer Login:** Dedicated access for consumers.
- **Professional Discovery:** Explore construction-related professionals.
- **Construction Solutions:** Discover home and building construction services.
- **Real Estate Solutions:** Connect with property professionals.
- **Search Functionality:** Find relevant professionals and services.
- **Responsive Design:** Accessible across desktop and mobile devices.
- **About & Contact:** Learn about the platform and get in touch.

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/Parvez37372/monarchconnect.co.in.git
```

2. Move the project folder into your local server directory.

3. Start Apache and MySQL using XAMPP.

4. Configure the database connection.

5. Import the required database into phpMyAdmin, if applicable.

6. Open the website:

```text
http://localhost/monarch/
```
